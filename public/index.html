One-liner SDK

Install @agfac/middleware and add one line to gate any Express or Fastify route.

SDK middleware

Install the SDK and gate routes directly. Recommended for new integrations.

// npm install @agfac/middleware import { agfac402 } from '@agfac/middleware/express'; const paywall = agfac402({ facilitatorUrl: 'https://agfac-production.up.railway.app', payTo: '0xYourWallet', }); // $0.10 per request app.get('/api/data', paywall({ price: 0.10 }), (req, res) => { res.json({ data: 'premium content', payment: req.x402 }); });

Reverse proxy

Register endpoints in the Endpoints tab. PayGate proxies requests — zero code changes to your API.

# Agents call your proxy URL curl https://agfac-production.up.railway.app/your-slug/v1/data # 402 → agent signs → X-PAYMENT header → PayGate settles → proxies to your API

Direct facilitator API

Handle 402 yourself and call the facilitator to verify and settle.

const res = await fetch('https://agfac-production.up.railway.app/facilitator/settle', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ x402Version: 2, paymentPayload, // decoded X-PAYMENT header paymentRequirements // your price + wallet }), }); const { success, transaction } = await res.json(); if (success) serveContent(); // USDC settled to your wallet
